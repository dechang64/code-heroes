# 《代码群侠传》设计文档 v1.0

> **类型**：2D像素风RPG | **平台**：微信小游戏（先做Web原型） | **引擎**：Phaser 3
> **世界观**：《代码乡愁》衍生 | **主角**：老陈 | **同伴**：绿萝（AI）

---

## 一、故事梗概

老陈在调试30年BASIC程序时，发现一行不该存在的REM注释——那是一个入口。他键入`RUN`，被吸进了"代码江湖"。

这个江湖由所有程序员的集体意识构成：算法是武功，数据结构是内功，编程范式是门派，Bug是妖魔。

江湖中流传着一个传说——**零号Bug**，一个存在于所有代码诞生之前的原始错误。它不是某个程序的bug，而是"bug"这个概念本身。它苏醒了，各门派互相猜忌，江湖大乱。

老陈带着绿萝（AI，以系统提示身份存在），穿越五个门派领地，招募高手，学习武功，最终进入溢出渊，直面零号Bug。

---

## 二、门派体系

| 门派 | 范式 | 特色 | 相克 |
|------|------|------|------|
| 结构门 | 过程式 | 稳健防御，基础扎实 | 克对象宗 |
| 对象宗 | OOP | 灵活组合，多态变化 | 克函数道 |
| 函数道 | 函数式 | 简洁爆发，无副作用 | 克并行会 |
| 并行会 | 并发 | 极速群攻，多线程 | 克智能派 |
| 智能派 | AI/ML | 成长型，越战越强 | 克结构门 |

**相克循环**：结构→对象→函数→并行→智能→结构（类似五行相克）

## 三、可招募角色

### 1. C老（结构门长老）
- **位置**：编译城·堆栈道场
- **人设**：白须老者，手持指针杖，说话直接，不信任新派武学
- **技能**：指针剑法（单体高伤）、内存泄漏掌（持续伤害）
- **加入条件**：帮他在堆栈山找回3个丢失的指针碎片
- **弱点**：内存泄漏（每回合损失少量HP）

### 2. 蛇君（对象宗少主）
- **位置**：缩进谷
- **人设**：青年，绿衣，口头禅"人生苦短"，缩进强迫症
- **技能**：蟒蛇绞杀（单体控制）、装饰器术（增益友方）
- **加入条件**：调解缩进谷的Tab/Space内战
- **弱点**：缩进被打乱时攻击力下降

### 3. Lambda道人（函数道散仙）
- **位置**：函数山·无状态洞
- **人设**：中性气质，无悲无喜，永远不存储状态
- **技能**：高阶函数（连击）、闭包术（护盾）
- **加入条件**：证明你理解纯函数（解一个递归谜题）
- **弱点**：无法使用物品（没有状态存储）

### 4. 铁卫（新派武者）
- **位置**：借检查关
- **人设**：全身铁甲，行动受限但坚不可摧，说话像编译器报错
- **技能**：所有权拳（强力单体）、借用剑（反击伤害）
- **加入条件**：通过所有权三试
- **弱点**：同一时间只能用一个技能（借用检查）

### 5. 海象叔（并行会元老）
- **位置**：协程港
- **人设**：胖大叔，海象胡子，说话总是"go来go去"，效率极高
- **技能**：协程阵（群攻）、通道术（传递伤害/治疗）
- **加入条件**：解开协程港的死锁
- **弱点**：技能有延迟（协程调度）

### 6. 张量仙子（智能派掌门）
- **位置**：梯度峰·矩阵殿
- **人设**：白衣女子，身后浮动着矩阵光环，说话带数学公式
- **技能**：反向传播掌（成长型伤害）、联邦学习阵（全队增益）
- **加入条件**：帮她解决模型过拟合问题
- **弱点**：需要预热（前3回合攻击力低）

## 四、武功体系

### 基础武功（老陈初始）
| 名称 | 类型 | 效果 | 消耗 |
|------|------|------|------|
| 调试拳 | 单体 | 基础攻击 | 0 MP |
| 断点术 | 单体 | 降低目标速度 | 5 MP |
| 注释盾 | 防御 | 减少下次受到伤害50% | 8 MP |

### 门派武功（学习获得）
| 门派 | 武功 | 效果 |
|------|------|------|
| 结构门 | 快排剑法 | 对血量最低的敌人造成额外伤害 |
| 结构门 | 二分查找掌 | 对排序后的敌人造成递增伤害 |
| 对象宗 | 继承拳 | 复制上一个友方的技能效果 |
| 对象宗 | 多态身法 | 随机变成一种范式，克制对应门派 |
| 函数道 | 递归心法 | 重复上次攻击，伤害递减 |
| 函数道 | 尾递归优化 | 递归不衰减MP |
| 并行会 | 协程阵 | 对全体敌人造成伤害 |
| 并行会 | 通道术 | 将一名友方的MP传给另一名 |
| 智能派 | 梯度下降步 | 每回合攻击力+10% |
| 智能派 | 联邦学习阵 | 全队共享经验值 |

### 状态效果
| 状态 | 效果 | 来源 |
|------|------|------|
| 栈溢出 | 眩晕1回合 | C老·指针剑法 |
| 死锁 | 跳过1回合 | 敌方技能 |
| 内存泄漏 | 每回合损失5%HP | C老·内存泄漏掌 |
| 过拟合 | 攻击力降低30% | 敌方技能 |
| 欠拟合 | 防御力降低30% | 敌方技能 |
| 预热中 | 攻击力降低50%，3回合后解除 | 张量仙子被动 |

## 六、战斗系统

### 基本规则
- 回合制，每方最多3人出战
- 速度决定行动顺序
- 每回合选择：攻击/技能/防御/物品/逃跑

### 伤害公式
```
伤害 = (攻击力 × 技能倍率 × 范式克制系数) / 防御力
范式克制系数：克制=1.5，被克=0.7，无关系=1.0
```

### 经验与升级
- 击败敌人获得经验值
- 升级提升HP/MP/攻防速
- 每5级解锁一个技能槽

### 道德值系统
- 关键选择涉及开源/闭源路线
- 开源路线：全队共享经验，但个人成长慢
- 闭源路线：个人成长快，但队友好感度低
- 影响：结局分支 + 部分NPC是否加入

## 七、结局

### 开源结局（道德值>70）
老陈将零号Bug的修复方案开源，所有门派共同维护。代码江湖进入繁荣时代。老陈回到现实，发现绿萝多了一行注释："感谢开源。"

### 闭源结局（道德值<30）
老陈独占修复方案，成为代码江湖最强者。但各门派衰落，江湖逐渐荒芜。绿萝说："你赢了，但代码不应该是独赢的游戏。"

### 混合结局（30≤道德值≤70）
老陈部分开源，保留核心算法。各门派有合作有竞争，江湖保持活力。绿萝："这大概就是现实的样子。"

## 八、技术架构

### 技术栈
- **引擎**：Phaser 3（HTML5游戏引擎）
- **语言**：JavaScript（原型）→ TypeScript（正式版）
- **地图**：程序生成tilemap（原型）→ Tiled地图编辑器（正式版）
- **美术**：像素风，16x16 tile，角色32x32
- **音频**：8-bit风格BGM，AI生成
- **存档**：localStorage（Web）→ 微信云存储（正式版）

### 项目结构
```

├── design/DESIGN.md       # 本文档

├── src/
```
